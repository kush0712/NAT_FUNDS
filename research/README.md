# Research Reproduction Guide

This directory contains all analysis scripts, raw data, and output files for the paper:

> **"Proxy Fidelity Under Data Scarcity: Evaluating Nifty TRI as a Stand-In for Unavailable BSE TRI in Indian Open-Source Fintech"**
> Kushagra Jaiswal & Harleen Khanuja, NAT_FUNDS Open Source Project

---

## Environment

```
Python 3.11
numpy==1.26.4
pandas==2.1.4
scipy==1.11.4
matplotlib==3.8.2
```

Install all dependencies at once:
```bash
pip install -r requirements.txt
```

## Step-by-Step Reproduction

### Prerequisites
The main application data files (`data/tri-data.json`, `data/benchmark-data.json`) and fund NAV cache files (`cache/nav_*.json`) must be present. They are generated by running the NAT_FUNDS platform (`npm start` from the project root). The research scripts read these files but do not modify them.

### Step 1 — Collect BSE Price data (if not already present)
```bash
# Requires: pandas, yfinance
python research/phase0/collect_bse_tri.py
# → writes research/phase0/data/bse_price_raw.csv
```

The `bse_price_raw.csv` file (120 months, July 2016–June 2026) is already committed to the repository and does not need to be re-downloaded unless you want to extend the date range.

### Step 2 — Run index correlation analysis
```bash
python research/phase0/analyze_correlations.py
# → writes research/phase0/outputs/correlation_results.csv
# → writes research/phase0/outputs/bootstrap_cis.csv
# → writes research/phase0/outputs/overlap_matrix.csv
# → writes research/phase0/outputs/figures/*.png
```

Expected output (broad-market pairs):
```
BSE SENSEX ↔ Nifty 50 TRI    r=0.965 [CI: 0.940, 0.980]  rho=0.951  n=120mo
BSE 100    ↔ Nifty 100 TRI   r=0.973 [CI: 0.955, 0.985]  rho=0.964  n=120mo
BSE 200    ↔ Nifty 200 TRI   r=0.973 [CI: 0.956, 0.984]  rho=0.964  n=120mo
BSE 500    ↔ Nifty 500 TRI   r=0.975 [CI: 0.958, 0.985]  rho=0.964  n=120mo
```

### Step 3 — Run metric-level error analysis (Alpha/Beta + rolling-window)
```bash
python research/phase1/compute_metric_error.py
# → writes research/phase1/outputs/metric_errors.csv       (static 36-month)
# → writes research/phase1/outputs/rolling_window_results.csv (all windows)
# → writes research/phase1/outputs/figures/*.png
```

Expected static results:
```
Mean ΔBeta:  +0.025  (SD=0.014, n=13 funds)
Mean ΔAlpha: -1.77%  (SD=0.53%)
```

## Data Availability Notes

| Series | Source | Status |
|--------|--------|--------|
| BSE Price (SENSEX, 100, 200, 500) | Yahoo Finance | ✅ Public, committed to repo |
| Nifty TRI (50, 100, 200, 500, CPSE, etc.) | NAT_FUNDS `data/tri-data.json` | ✅ In repo root |
| BSE TRI (SENSEX TRI, etc.) | BSE AllIndices API | ❌ Deprecated — unavailable |
| Fund NAV history | `cache/nav_*.json` (generated by app) | ✅ Present after running app |

The fundamental limitation of this study — that BSE TRI data is unavailable and therefore the proxy-vs-target comparison cannot be made directly — is documented in the paper (§IV-A and §VI-C).
